# Surface brief: index.html (alligator.sh landing page)

## Scope and mode
The single public page of alligator.sh. Persuade: a developer decides Alligator is real and serious and joins the CLI launch list.

## Audience, job, action
Developers running coding and code-review agents (Codex first, other MCP clients). One action with one name: "Notify me" (nav, hero "Notify me at launch", section "// Launch list", form button, footer). Formspree endpoint; submit disables while sending; no on-device fallback.

## Proof and content
Claims-only: no fabricated tool output, graph renders, metrics, customers, or docs links. The dated readiness checklist (16 of 22 launch checks) is the page's trust asset. All copy is the owner's.

## Direction and memorable moment
The incumbent identity, kept by decision (2026-09-22): dark base, cyan accent, Orbitron display, Share Tech Mono labels, Rajdhani body, scanlines, custom cursor, and the animated particle-graph canvas, which is the moment the owner's reviewer valued most. Refinements fix defects inside this look.

## Constraints
Single static index.html on GitHub Pages. Functional text never under 12px; tracking on labels at most .2em; tap targets at least 37px in the nav and 44px for buttons; mobile keeps the "Notify me" nav link; the canvas runs at 45 nodes under 700px and pauses while the tab is hidden; reduced motion disables the canvas, animations, and smooth scroll.

## Unresolved
No og:image (card type set to summary). No logo or mark. Guides listed as "Complete" in the readiness table have no public links yet.
